# AIOps Sentinel

Plateforme d'agents IA en langage naturel pour interroger une infrastructure :
inventaire structuré (PostgreSQL, Agent SQL) et documentation technique
collectée automatiquement (Crawl4AI, indexée dans Qdrant, Agent RAG).

## Statut

Projet en cours de construction, phase par phase.

- [x] Phase 1 — Cadrage & architecture
- [ ] Phase 2 — Socle de données (PostgreSQL + Qdrant + Crawl4AI)
- [ ] Phase 3 — Agent SQL infra
- [ ] Phase 4 — Agent RAG documentation
- [ ] Phase 5 — Orchestration multi-agents (MCP)
- [ ] Phase 6 — API Gateway (FastAPI + Swagger)
- [ ] Phase 7 — Observabilité (Splunk) + vLLM (bonus GPU)
- [ ] Phase 8 — Déploiement Kubernetes (Oracle Cloud)
